
# routeine

This is an interactive MERN-based web application designed to help users visualize and manage their daily events and travel routes on a dynamic map interface, making day planning intuitive and efficient.


## Authors

- [Swastik Dash](https://www.github.com/SwasD02)


## Tech Stack

**Client:** React, TailwindCSS, React-Leaflet (Map Interface)

**Server:** Node.js, Express.js

**Database:** MongoDB

**Mapping & Routing:**	OpenStreetMap (Tiles)

**APIs:**	OpenRouteService (Route Generation), LocationIQ Geocoding (Address-to-GPS Conversion)


## Run Locally

Clone the project

```bash
  git clone https://github.com/SwasD02/routeine
```

Go to the backend project directory

```bash
  cd backend
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```

Once the backend runs, go to the frontend directory on another CLI tab

```bash
  cd frontend
```
Start the server

```bash
  npm run build
```
